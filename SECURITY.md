# Security policy

## Supported versions

Security fixes go into the latest release. Izar has no long-term support branches.

## Report a vulnerability

Report vulnerabilities privately through
[GitHub security advisories](https://github.com/glisseo-dev/project-izar/security/advisories/new).
Do not open a public issue for a vulnerability.

Include the affected module and version, the steps to reproduce the problem, and its impact.
You can expect an acknowledgement within a few days. We will keep you informed while we
investigate and credit you in the advisory if you want.
